# Travel and Tourism Management System

A simple travel and tourism website developed using HTML, CSS and JavaScript as part of the Software Engineering Outsource Lab project.

## About the Project

The Travel and Tourism Management System helps users explore popular tourist destinations, view available tour packages and book their trips through a simple website.

## Live Demo

Visit the website:

https://beamish-sorbet-84d7e6.netlify.app

## Features

- **Home Page:** Introduction to the travel website.
- **Popular Destinations:** Explore popular tourist destinations.
- **Tour Packages:** View packages with images, prices and travel duration.
- **Booking System:** Book a trip by entering your name, email, destination and travel date.
- **Price Display:** Automatically shows the package price according to the selected destination.
- **Booking Confirmation:** Displays booking details after successful booking.
- **Contact Information:** Provides contact details for users.

## Technologies Used

- HTML – Website structure
- CSS – Styling and page design
- JavaScript – Booking functionality and interactivity

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. You can also use the Live Server extension in VS Code.

## How to Use

1. Open the website.
2. Explore the available destinations and tour packages.
3. Go to the Booking section.
4. Enter your details and select a destination.
5. Check the package price and click Book Now.
6. View your booking details on the confirmation page.

## Note

This is a front-end project developed for educational purposes. It does not use a backend database or an online payment system. Booking details are temporarily stored in browser local storage and removed after being displayed on the confirmation page.
